Introduction

The project is a console model of a self-service retail kiosk. A customer's order is assembled from products with optional extras (gift wrap, warranty, engraving), a promotion is applied, the payment is simulated with card, cash or QR, and a successful sale reduces the stock and updates a live sales dashboard and a low-stock alert. The application uses Java 17 and the standard library only. Six design patterns (two creational, two structural, two behavioral) work together in one checkout flow.

Structure

Main.java is the only class outside the six pattern packages. It creates the objects, runs six checkout scenarios and verifies the results. Every other class lives in a pattern package, with subpackages that follow the pattern roles (for example factory/creators and factory/methods).

Checkout flow

The Builder creates the order, and decorated products are ordinary items in it. KioskFacade.checkout() groups the quantities by SKU and checks the stock, asks the Strategy for the final price, asks the Factory Method for a payment object and processes it. After an approved payment it reduces the stock and publishes events to the Observers. A declined payment or missing stock stops the flow before anything is changed.
