1. Builder and Strategy

Implemented by Kantarbayev Alibek

Builder (creational)

An order is assembled step by step: a customer name and any number of product lines. OrderBuilder collects the lines and build() returns an immutable Order with a generated id. The Order constructor is package-private, so the only way to obtain an order is the builder. An order with no items is rejected. OrderDirector stores two ready-made recipes (single item, pair of items), which is the Director role of the pattern. Decorated products (gift wrap, warranty) are passed to the builder like any other Product.




Strategy (behavioral)


A promotion is a PricingStrategy: it receives the order and returns the discount amount. PriceCalculator is the stateless context: the strategy is passed into every call, so one shared calculator can serve any number of orders with different promotions and no hidden state. Four strategies exist: no discount, percentage, buy-one-get-one and bundle. A new promotion is a new class; nothing else changes (Open/Closed). All money is BigDecimal rounded half-up to two decimals, so totals such as $100.80 are exact.
