3. Decorator and Observer

Implemented by Tikzhanov Aldiyar

Decorator (structural)

Extras are added to a product at run time without subclassing every combination. ProductDecorator implements Product, wraps another Product and passes the SKU through unchanged, so stock is still counted per real product. GiftWrap adds $3.00, ExtendedWarranty adds 15% and Engraving adds $5.00. Decorators can be stacked: scenario 6 of the demo orders new GiftWrap(new Engraving(headphones)), and the price and name are composed layer by layer. Every decorator can be used wherever a Product is expected (Liskov Substitution).






Observer (behavioral)


After a successful checkout the facade only publishes events; it does not know who reacts. EventPublisher is the subject. A listener subscribes to one event type, for example SalesDashboard to SaleEvent and StockAlertLogger to LowStockEvent, and receives only events of that type. The generic interface KioskListener<E> removes the instanceof checks that a single shared callback would need: a new event type or a new listener is added without editing existing observers (Open/Closed). Listeners can also unsubscribe; Main checks that an unsubscribed dashboard no longer receives sales.
